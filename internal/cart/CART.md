# Cart 
Пользовательская корзина, для сохранения товаров, CartItem - позиция в корзине


Доменная модель корзины представляет структуру данных, с набором полей:

    Id - уникальный идентификатор модели
    UserID - пользовательский идентификатор корзины, определяет какому пользователю принадлежит конкретная корзина
    Status - статус корзины "active", "checked_out" (значение "abandoned" в коде пока не используется)
    CreatedAt - дата создания корзины
    UpdatedAt - дата обновления корзины
    Items - позиция в корзине
    
Доменная модель позиции в корзине, представляет структуру данных с набором полей:

    Id - уникальный идентификатор модели
    CartId - идентификатор корзины
    ProductId - идентификатор продукта помещенного в корзину из каталога
    Quantity - количество элементов в корзине
    PriceSnapshot - цена товара, зафиксированная на момент добавления позиции в корзину

## DTO
DTO - структуры данных для общения с пользователем, где:
1. Request - данные которы передает пользователь программе
2. Response - ответ программы пользователю

## Методы Cart
По скольку корзина реализуется неявно, было принято решение использовать гибридный метод:  ```CreateOrGet```,
который получает корзину и возвращает ее пользователю или создает, если той не существует

```Checkout``` - переводит корзину в статус "checked_out": возвращает ошибку, если корзина уже не в статусе "active",
либо если в ней нет ни одной позиции

## Методы CartItem
1. Create - создает позицию в корзине
2. Update - обновляет данные корзины, а именно количество товаров
3. Delete - удаляет позицию из корзины


## Гостевая корзина
Реализация гостевой корзины реализована через NoSQL базу данных:
Redis, с методами:
1. GetGuestCart - пытается получить гостевую корзину по заданному ключу пробрасываемому из контекста, в случае если ее нет, возвращает nil без создания корзины
2. AddItemToCart - пытается получить корзину, если ее не существует, создает новую доменную модель, по умолчанию со статусом "active" создает флаг ```found``` с булевым значением, итерируется по полученной корзине, и проверяет productId, если находит сходство, прибавляет количество позиций переданных пользователем к доменной модели, в случае если !found, обращаемся к каталогу и получаем наш товар по идентификатору, добавляем новую позицию с productId, quantity и ценой товара из каталога (PriceSnapshot), сохраняем корзину в Redis
3. UpdateItemIntoCart - пытается получить гостевую корзину, если ее нет, выбрасывает ошибку ```CartNotFound```, ищет продукт, если найден меняет его количество, если нет выбрасывает ошибку ```ProductNotFound```, сохраняет корзину в Redis
4. DeleteItemIntoCart - пытается получить корзину, если ее нет, выбрасывает ошибку ```CartNotFound```, ищет продукт по productId, если не найден - выбрасывает ошибку ```ProductNotFound```, если найден - удаляет позицию и сохраняет корзину в Redis
5. MergeGuestCart - пытается получить гостевую корзину, в случае промаха выбрасывает ошибку, создает Postgres корзину, сохраняет все в новый CartItems, удаляет гостевую корзину
